# Portfolio web — Matías Britez

## Archivos
- `index.html` — página principal
- `style.css` — diseño y responsive
- `script.js` — menú móvil, animaciones y navegación
- `assets/foto-matias.jpeg` — foto original utilizada en el sitio

## Para activar el botón "Descargar CV"
Colocá tu PDF dentro de esta misma carpeta con el nombre:

`CV-Matias-Britez.pdf`

## Para abrir
Hacé doble clic en `index.html`.

No requiere instalación.

## Para publicar
Podés subir la carpeta a GitHub Pages, Netlify, Vercel o cualquier hosting estático.

IMPORTANTE: el PDF debe estar en la misma carpeta que index.html y llamarse exactamente CV-Matias-Britez.pdf. Si tu archivo tiene otro nombre, renombralo así.
